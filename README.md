# Fragrance House — Premium Perfume Shop Website

A luxury 3-page e-commerce website for a Pakistani organic fragrance brand. Built with pure HTML, CSS, and JavaScript.

## Features

- **Dark luxury theme** — deep black (#0d0d0d) + gold (#c9a225) + cream (#f5f0e8)
- **Fully responsive** — mobile-first design
- **3 pages** — Home, Shop, About & Contact
- **Interactive chatbot** — helps customers find their perfect scent and place orders
- **Cart drawer** — slides from right with WhatsApp ordering
- **Product filters** — category, price range, and search
- **Smooth animations** — fade-in on scroll effects
- **WhatsApp integration** — order directly via WhatsApp

## Pages

### Home (`index.html`)
- Full-screen hero with dark overlay
- Stats bar (500+ Fragrances, 100% Organic, Nationwide Delivery, 10+ Years)
- Featured products (4 cards)
- Why Choose Us section
- Customer reviews (5 stars)

### Shop (`shop.html`)
- Filter bar (category, price range, search)
- 9 product cards in responsive grid
- Size options (6ml/12ml/20ml)
- WhatsApp order integration

### About & Contact (`about.html`)
- Brand story
- Our Values (3 cards)
- Contact form
- Contact information & map placeholder

## Tech Stack

- HTML5
- CSS3 (Custom Properties, Grid, Flexbox)
- Vanilla JavaScript
- Google Fonts (Cormorant Garamond + Inter)
- SVG Icons (no external icon library needed)

## Getting Started

Simply open `index.html` in a web browser. No build tools required.

## Brand

**Fragrance House** — Premium Organic Attars & Perfume Oils, Lahore, Pakistan
